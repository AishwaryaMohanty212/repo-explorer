# Repo Explorer

React + TypeScript app that searches GitHub repositories through the public GitHub REST API and lets you save favourites (persisted with localStorage).

**Live demo:** https://YOUR-USERNAME.github.io/repo-explorer/

## Features
- Third-party REST API integration with loading and error handling
- Typed React components using hooks (`useState`, `useEffect`)
- Saved list persisted in the browser
- Automatic CI/CD: every push to `main` builds and deploys to GitHub Pages

## Run locally
```bash
npm install
npm run dev
```
